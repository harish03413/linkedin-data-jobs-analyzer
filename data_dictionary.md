# Data Dictionary

| Column | Description |
|---|---|
| id | Unique identifier for the job posting |
| title | Job title |
| company | Company that posted the job |
| location | Location of the job |
| link | URL of the job posting |
| source | Source website or platform |
| date_posted | Date when the job was posted |
| work_type | Work arrangement; currently empty |
| employment_type | Employment category; currently empty |
| description | Full job description |
| skill_python | Whether Python is mentioned |
| skill_sql | Whether SQL is mentioned |
| skill_excel | Whether Excel is mentioned |
| skill_aws | Whether AWS is mentioned |
| skill_azure | Whether Azure is mentioned |
| skill_machine_learning | Whether machine learning is mentioned |
